# 获取降级链 playbook（§3.2 配套）

> 使用者线：§3.2 步骤 2（浏览器降级）与步骤 5（渠道四档）的操作细节。全部用能力语言书写，宿主工具名见 SKILL.md §1 适配表。

## 1. 浏览器路线标准动作

前置：先查宿主浏览器已开标签页——用户可能已自行打开目标页，能复用就不新开。

1. **DOI 跳转**：导航 `https://doi.org/{doi}`，静置 5–10 秒（出版商多级跳转 + 渲染）。
2. **放行判定**：页面含正文结构标记（文章标题 + 章节层级 + 图表元素）→ 可提取；含挑战/验证码标记（Cloudflare、Imperva 类）→ 不自动绕过，保留现场请用户人工处理，用户放行后重试一次。
3. **页面内提取**：在页面上下文执行提取脚本，要点：
   - 正文容器按常见文章结构定位（article 主容器 → 逐节点遍历去重），不依赖单一选择器。
   - 超长正文分段返回（如每段 ≤30000 字符），或用宿主的「执行结果落盘」能力直接写文件，避免超长返回体截断。
   - 脚本体被包进函数执行时必须显式 `return`（异步 IIFE 结尾 `return (async () => { ... })()`）——漏 return 无报错、结果为空，属静默失败。
4. **机构挡板识别**：返回的是无正文无摘要的 HTML 壳（几 KB 且只有导航与「Content unavailable」类文案）→ 判「机构未订阅」，不再重试同一出版商直链，直接进渠道四档。

## 2. pdf 直链副本

- 同域 fetch 携带凭据 → base64 → 校验文件头魔数 `%PDF` → 解码落盘。缺 `needAccess` 类参数的直链先试裸 URL，失败再加参数族。
- 浏览器原生下载可能触发「询问保存位置」弹窗：用户开启该开关时，下载前提醒用户放行；未开启则优先走 fetch 落盘路线。
- 大文件（SI 附件、>5 MB blob）在页面内转 base64 可能超时：先轻量探测（只取头部魔数）确认可达，再决定整文件传输或改走原生下载。

## 3. 扫描版判定

- 提取字符数低于约 3000（正文应有的量级远大于此）且按页提取均为空 → 判扫描版，进宿主 OCR 能力或标「未获取」。
- 判定只作降级依据，不回写题录。

## 4. 白名单渠道（③档）实操

- 渠道条目从 `project.json` 的 `compliance.tier3_allowlist` 读取；条目可含多个镜像地址，按序尝试。
- 通用动作：请求 `https://{镜像}/{doi}` → 从返回页解析 pdf 直链（iframe / embed / 保存按钮链接）→ 下载后校验 `%PDF` 魔数 → 入 `papers/`，台账记渠道名。
- 镜像域名不定期变更：全部镜像失败即停，标失败原因，不自行扩渠道（扩渠道属④档，须问询）。
- 台账必须记录：渠道名、命中日期、授权依据（`tier3_allowlist` 写入人/日期）。

## 5. 并发纪律

- 涉网获取（直链、浏览器、白名单渠道）串行或 ≤2 并发；单出版商连发失败 ≥2 次即换档或停点问询，不连坐升级验证码。
- 读本地文件的提取/摘要子会话不受此限（不触发反爬），但派发数量以宿主子会话稳定运行为限。
