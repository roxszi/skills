# paper-review-kit（同学原版 v0.3.0）借鉴分析

> 2026-10-22 应用户要求审视 `https://github.com/castiel0519/Paper-review-kit/tree/main/skills/paper-review-kit`，对照 paper-review-writer v0.2.0 找可借鉴点。供 v0.2.x/v0.3 改造拍板用。

## 一、两版定位差异（借鉴判断的前提）

- 同学版：交付导向——读书报告 DOCX + 每篇 2 页 PPT + 可选综述；PDF 中心（PyMuPDF 生态）；一键前半程。
- 本技能：综述导向——结构化条目 + 素材包 + 引用闭环；文本中心（pdfjs 提取 + HTML 混合获取）；两处强制停点。
- 结论：交付物类脚本（PPT/DOCX）维持裁撤（宿主文档能力已覆盖）；借鉴点集中在「信息供给」与「自检闭环」两类。

## 二、可借鉴清单（按价值/成本排序）

| # | 借鉴点 | 来源脚本 | 价值 | 成本 | 建议 |
|---|---|---|---|---|---|
| 1 | 图题 caption 原文进 digest | extract_figs.py（启发，实现不同） | 高：化学文献 Scheme caption 完整描述合成路线/框架，子会话读 caption 即知图意，evidence_figs 更准 | 低：digest 内 ~20 行（图题命中处向后截取 300–500 字符） | 采纳 |

## 三、明确不借鉴（留决策理由）

- **一键前半程（run_pipeline.sh）**：本技能两处强制停点（清单冻结/获取完成问询）是实战教训换来的一票否决设计，一键跑完与停点互斥。
- **PPT/DOCX 内置生成 + check_layout（文本溢出估算）**：宿主文档技能已覆盖；维持 0.1.0 裁撤决策。
- **Scheme 图像裁剪（PyMuPDF 位图/矢量聚类 + figure_overrides bbox）**：本技能文本中心，Node 侧位图渲染需引入 canvas 依赖，成本高收益薄；用 #1 的 caption 原文替代其 80% 价值。
- **framework_steps/paradigm_tags 等框架叙事字段**：面向「每篇 2 页 PPT」的叙事结构；本技能 method/results 字段承载更实，字段膨胀有 token 成本。

## 四、同学版值得肯定的其他设计（已在 v0.2.0 或不适用）

- 一句话原则置于 SKILL.md 开头（主 Agent 不读全文与超大 digest，只读 brief）——本技能分散在 §3.3/§4，可提炼一句到开头（顺手做，不计项）。
- 每篇一次派发、先落盘再返回、文件存在性回收——v0.1.0 迁移时已继承。
- 失败处理三章（README「典型失败处理」）结构清晰——本技能 playbook 已覆盖且更细。
