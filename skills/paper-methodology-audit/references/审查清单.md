# 方法学审查清单

按层逐项过。每项写成「看到 X → 追问 Y」，命中才展开，不命中跳过。

---

## 一、通用统计与建模

- 看到拟合参数数目 → 追问数据点数与残差自由度。自由度 ≤ 0 时参数不可辨识，拟合无意义。
- 看到 R² → 追问是否报告残差图、置信区间、样本量。R² 高而自由度不足，按过拟合处理。
- 看到单变量自变量个数少、点却很多 → 追问该参数能否与其他贡献分离。作者已声明无法区分时，指出该参数不能归因。
- 看到「速率常数」「效率」等量纲名词 → 追问定义式与单位是否匹配。光学信号、峰面积、计数率不得直接当反应速率常数。
- 看到用描述性统计支撑因果结论 → 追问样本是否独立、是否设对照组、是否重复。
- 看到模型比较 → 追问选择判据是 AIC／交叉验证还是残差大小。仅凭 R² 选模型不成立。
- 看到外推区间的预测 → 追问是否有域外验证。

## 二、可复现性

- 看到参比电极换算式 → 追问常数对应的具体条件（盐桥电解液浓度、温度）。条件未报则全部电位标度不可复现。
- 看到循环伏安 → 追问 iR 降是否校正或讨论、扫描速率、参比与工作电极距离、池体积。
- 看到峰电位作为论据 → 追问 iR 降与传质限制对该峰位的影响。峰位论证在未校正 iR 时不成立。
- 看到体积、浓度、pH、温度中任一缺失 → 追问其余是否齐全。核心参数缺一项即判缺失。
- 看到方法学验证声明 → 追问六参数逐项是否给出数据，非仅声明。
- 看到「数据可得」 → 追问可得范围与是否含原始数据。仅 processed data 不支撑重拟合。

## 三、物理意义与机制

- 看到机制推断 → 追问每一步是否有正交证据。单一表征不足以支撑多步路径。
- 看到光谱峰位归属 → 追回到标准谱库原文核对频率与模式标签，不采信正文转述。
- 看到「首次」「未见报道」→ 追问该主张是否被自身引文推翻。作者引文中若有更早同类工作，此项判硬伤。
- 看到分子振动归属与增强机制混写 → 追问增强机制的物理可能性。弱局域增强因子的第二金属、新生基底等说法须核对激发波长与材料。
- 看到 X 同时出现又同时消失 → 追问是否真支持相继转变。同时出现同时消失不支持分级转变。
- 看到亚稳相或易混相归属 → 追问是否有独立手段确认。单靠重叠峰位不足以区分。
- 看到阴离子／配体参与反应 → 追问双电层与离子富集效应是否已排除。
- 看到信号增强 → 追问是热点数变化、覆盖度变化还是分子本征散射变化。三者不可混谈。

## 四、领域专属

先判本文落在哪几个子域，只过命中的子域，其余整节跳过并在交付中写出跳过范围。一篇文献通常命中一至两个子域。

### 电化学

- 看到可逆性声明 → 追问峰电位差、峰电流比、峰电位随扫描速率的依赖。
- 看到析出或沉积产物 → 追问电流效率、沉积量是否独立称量。
- 看到电位窗口结论 → 追问是否随 pH 平移；未给 pH 的窗口值不可引用。
- 看到修饰层保护或钝化声明 → 追问对照是否为同基底不同修饰、以及裸基底对照。

### 光谱与 SERS

- 看到增强因子 EF → 追问归一化方式、是否扣除吸附量差异、基底批次重复性。
- 看到浓度—强度定量关系 → 追问基底在测量过程中是否老化。热点被消耗或填塞时该关系不可直接用。
- 看到自组装单分子层作识别元件 → 追问覆盖度在反应过程中是否稳定、被产物埋入后是否仍可见。
- 看到谱带归属 → 追问官能团归属是否与介质条件一致。同一波数在不同 pH、离子强度下归属可反号。
- 看到无拉曼对照 → 追问有无法拉曼的空白基底对照。没有该对照则增强机制无法归因。

### 定性定量分析

- 看到分类判据 → 追问训练集与测试集是否独立、有无同源泄漏。
- 看到多变量模型 → 追问交叉验证方式、预处理是否在折内完成。
- 看到 LOD／LOQ → 追问是 s/n、3σ 还是其他定义，各方法是否统一。

### 催化

- 看到选择性提升 → 追问活性位点是否已确认提升来源，还是仅电流密度变化。
- 看到稳定性循环 → 追问每圈定量、是否有表征证明结构未变。

## 归类判据

- **硬伤**：结论所依赖的前提不成立，引用会出错。例：把光学衰减当速率常数；「首次」被自身引文推翻；用未校正 iR 的峰位作论据。
- **存疑**：数据不足以判定，需回查原始引用。例：模式标签与晶体空间群不符；增强机制表述过强；亚稳相归属缺独立确认。必须给出回查路径。
- **缺失**：信息未报告，致不可复现。例：参比条件未报、n 与误差棒未报、图内数值正文未列。

## 分级纪律

- 未报告 ≠ 未做。只判缺失，不推断作者行为。
- 存疑降级规则：给不出回查路径的存疑项，降为缺失。
- 零命中时明写「未发现实质问题，已核对范围：<列出层与项>」，不以沉默充当通过。
- 未过的子域不算通过。零命中声明须同时列出跳过的子域，否则「未发现实质问题」的覆盖面被高估。
- 审查结论与引用建议分开写。用户可只取其一。
