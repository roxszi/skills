# CHANGELOG - paper-methodology-audit

> 本文件面向本技能的编辑者。SKILL.md 是运行时注入面，只放执行指令；版本历史与维护契约一律落本文件。

## 维护契约

- 本技能必须自足可迁移：宿主工具名只进 SKILL.md §1.0 适配表，正文与 assets 只写能力名。
- 私有资产（本地文献库、db、私有脚本路径、本机环境断言如「只有 bun」）不入本技能，由各宿主的钩子文件（如 TOOLS.md）承载。
- 运行时假设只有一条：能跑零外部依赖的 ESM 脚本（node ≥ 20 或 bun）。
- 面向用户的表述（提问、申报卡、交付、汇报）一律用自然语言：档位代号（L0／L1／L2）、内部字段名（slug、read_status、evidence_*）与评测指标只允许出现在本技能文档内部、条目 JSON 与校验脚本中，不外泄到用户对话。问用户选档时问「速览／全文精读／核心精读」，不问「走 L1 还是 L2」。
- 改动脚本后跑 `node tests\run-tests.mjs` 全过才算完成；改 frontmatter description 后按 `references\触发评测流程.md` 重跑 `--lexical` 离线检查。
- 修改 SKILL.md 或本文件后，在下方版本历史追加条目，只写改了什么。
